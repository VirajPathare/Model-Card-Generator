# Model Card: Model Card & Datasheet Generator

## 📋 Model Details
- **Developed by:** Viraj Pathare
- **Model Type:** Pipeline / LLM Wrapper
- **Core Components:** 
  - **Generative LLM:** Groq API (`openai/gpt-oss-20b`)
  - **Text Classifier:** DistilBERT (`typeform/distilbert-base-uncased-mnli`)
  - **Image Generation:** Pollinations AI API (Stable Diffusion backend)
  - **Audio Generation:** gTTS (Google Text-to-Speech)
- **Language:** English
- **License:** MIT

## 🎯 Intended Use
- **Primary Use:** Assisting ML developers, researchers, and auditors in automatically drafting standardized Model Cards and Dataset Datasheets from raw Hugging Face README files.
- **Primary Users:** AI practitioners, compliance auditors, and computer science students.
- **Out-of-Scope Use:** This tool is not intended to generate legally binding compliance certificates. Generated text must **never** be published without manual human review.

## ⚙️ System Factors
- The output quality is highly dependent on the structure, quality, and completeness of the source README provided.
- The DistilBERT classifier analyzes only the first 1,500 characters of the README for gap analysis (limitation of the model's context window).
- The LLM input is truncated to 2,000 characters to prevent API rate limits and excessive token consumption.

## 📊 Metrics & Evaluation
- **Latency:** Average end-to-end generation time is ~2.5 seconds.
- **Guardrail Accuracy:** The regex-based hallucination checker successfully flags fabricated metrics (e.g., "95% accuracy") that are generated by the LLM but are ungrounded in the source README.
- **Evaluation Data:** Tested and evaluated on public Hugging Face models: `bert-base-uncased` and `distilbert-base-uncased-finetuned-sst-2-english`.

## ⚖️ Ethical Considerations
- **Hallucination Risk:** LLMs are prone to generating fabricated facts. While this app includes a guardrail to warn users of ungrounded numbers, **human review is strictly required** before publishing.
- **Bias:** The LLM may inadvertently generate biased text if the source README contains biased language or if the model's pre-training data contains societal biases.
- **Privacy:** No user data is stored or transmitted. The app only reads publicly available Hugging Face READMEs.

## ⚠️ Limitations
- **Gated Models:** The app cannot fetch READMEs for gated models (e.g., Meta's Llama series) due to access restrictions. Users must manually paste the README text into the UI.
- **Formatting Glitches:** PDF generation via `ReportLab` may occasionally misalign complex Markdown tables from the LLM output.
